# Runtime Brig

Пакет `internal/runtime/` (+ `internal/prelude/` для встроенных функций §9.1).
Значения Brig — неизменяемые Go-объекты; коллекции — персистентные
(структурный sharing, принцип #13). Этот скилл описывает инварианты и грабли
пакета, а не дублирует §2 / §5.3 / §13.

## Когда применять / не применять

**Применять:** правки `internal/runtime/**` и `internal/prelude/**` —
`BrigValue`, коллекции, структурный sharing, равенство, term order,
сериализация значений.

**Не применять:** VM (интерпретация байткода, стек, вызовы) — свой скилл;
парсер, лексер, AST, CLI — свои скиллы. Runtime — только значения и
коллекции; как их гоняет VM — не здесь.

## Инварианты

Это критично. Ломать нельзя без обновления спецификации.

1. **Иммутабельность (принцип #13).** Все операции над коллекциями возвращают
   **новое** значение, старое остаётся доступным. `Vec.set`, `Map.put`,
   `Set.add` **не мутируют** приёмник.
2. **Структурный sharing.** Новое значение переиспользует подструктуры
   старого; копирования целиком быть не должно. Проверяется
   property-тестами на сложность (см. «Проверка»).
3. **`Map.get` возвращает `Option`, не `nil`.** `m["a"]` — всегда `Some(v)`
   или `None`; `nil` в runtime не существует (принцип #4).
4. **Атомы интернированы.** `Atom.intern(name)` возвращает канонический
   экземпляр; сравнение — по указателю, не по строке. Хранение атома как
   строки без интернирования ломает identity-сравнения.
5. **Равенство — структурное, кроме `Pid`/`Ref`/`Function`.**
    - `Ok(1) != (:ok, 1)` — вариант vs кортеж.
    - `X{...} != Y{...}` — номинальные записи сравниваются по тегу + поля.
    - `1 == 1.0` — численное смешение разрешено.
    - `Decimal × Float` — **ошибка**, не приведение.
    - `Pid`/`Ref`/`Function` — identity, нестабильны между запусками.
6. **Term order фиксирован §5.3.** Порядок между видами — не «по алфавиту»,
   а по таблице §5.3. `Bool` перед атомами; `Range` — в позиции, указанной
   §5.3 (не «где-то между ними»). При добавлении нового вида значения —
   обновить `order.go` и §5.3 синхронно.
7. **`Range` — first-class значение (§2.5).** Не сахар над парой Int;
   участвует в равенстве, term order, сериализации.
8. **Сериализация (§2.9–2.10, §11).** `Ok(1)` → `{"__type__": "Ok", "value": 1}`
   (Should); `Pid`/`Ref`/`Function` — **не поддерживается**, ошибка, не
   «пропустить поле».
9. **Прелюдия — только в `internal/prelude/`.** Встроенные функции §9.1
   (коллекции, конверсии, акторы, I/O, эффекты) не должны быть размазаны по
   `runtime`. Shadowing — info-диагностика, доступ через `import Prelude`.

## Быстрый справочник значений (источник — §2.11)

| Значение                   | Равенство                  | Замечание                   |
| -------------------------- | -------------------------- | --------------------------- |
| `Int` / `Float`            | численно (смешение)        | `1 == 1.0` — true           |
| `Decimal`                  | точно                      | `Decimal × Float` — ошибка  |
| `Bool`                     | по значению                | примитив                    |
| `Range`                    | структурно, `(start, end)` | `1 to 10 == 1 to 10`        |
| атом                       | по имени (интернирован)    | `:ready?`                   |
| `Bytes`                    | по байтам                  |                             |
| `Str`                      | по кодпоинтам              | UTF-8 by construction       |
| `Tuple`                    | структурно                 | `..` запрещён               |
| `List`                     | структурно, поэлементно    | O(n); паттерны с `..rest`   |
| `Vector`                   | структурно                 | exact-length pattern        |
| `Map`                      | по набору пар              | частичный матчинг по ключам |
| `Set`                      | по набору элементов        |                             |
| анонимная запись           | структурно, по полям       |                             |
| номинальная запись         | тег + поля                 | `X{...} != Y{...}`          |
| `Ok/Error/Some/None`       | тег + поля                 | `Ok(1) != (:ok, 1)`         |
| `()` Unit                  | единственное значение      | заменяет `nil`              |
| `Pid` / `Ref` / `Function` | identity                   | нестабильно между запусками |

Если таблица расходится с §2.11 — прав §2.11; таблица здесь только для
навигации.

## Коллекции

| Коллекция | Структура            | Сложность                              | Литерал         |
| --------- | -------------------- | -------------------------------------- | --------------- |
| Vec       | trie (Clojure-style) | append O(1) amortized, read O(log32 n) | `%[...]`        |
| Map       | HAMT                 | put/get O(log32 n)                     | `%{ "a" => 1 }` |
| Set       | HAMT                 | add/has O(log32 n)                     | `set(1, 2, 3)`  |
| List      | cons (односвязный)   | head O(1), append O(n)                 | `list(range)`   |

- **Vec вне границ** — `raise`, не «вернуть None».
- **Map-спред** `%{ ..m, "c" => 3 }` — новый Map, старый неизменен.
- **Record update** `{ ..u }`, `User{ ..r }` — сохраняет вид (номинальный
  остаётся номинальным).

## Пример: персистентный `Map.put`

Правильная форма (упрощённо, для навигации по коду):

```go
// internal/runtime/map.go
func (m *Map) Put(k Value, v Value) *Map {
    // HAMT: путь копируется, остальные ветки переиспользуются
    if m == nil {
        return newMapWith(k, v)
    }
    // BitmapIndexedNode / ArrayNode / CollisionNode — рекурсивно
    newRoot, _ := m.root.assoc(hash(k), k, v)
    return &Map{ root: newRoot, count: m.count + 1 } // старый m не тронут
}
```

При правке любой коллекции **обязательно** проверять:

1. **Иммутабельность:** `old := m; _ = m.Put(k, v); assert(old.Len() == была)`
   — старый приёмник не изменился.
2. **Структурный sharing:** property-тест на глубину копирования; `Put` не
   должен копировать всё дерево.
3. **Option-семантика:** `Get` возвращает `Some`/`None`, не `nil`/значение.
4. **Term order:** новый вид значения вставлен в `order.go` на правильную
   позицию §5.3.

## Прелюдия (§9.1)

Живёт в `internal/prelude/`, не в `runtime`:

- **Коллекции:** `map filter find fold all any len`; конструкторы `list set`.
- **Конверсии:** `to_str to_int to_float`.
- **Акторы:** `send spawn spawn_linked link watch unwatch self make_ref mailbox_size`.
- **I/O:** `print eprint log`.
- **Эффекты:** `assert raise trap`.

Shadowing прелюдии — info-диагностика; доступ через `import Prelude` →
`Prelude.map`.

## Сериализация (§2.9–2.10, §11)

| Значение                   | JSON                             | Статус                  |
| -------------------------- | -------------------------------- | ----------------------- |
| `User{ id: 1 }`            | `{"id": 1}`                      | ok                      |
| с `{ type_tag: true }`     | `{"__type__": "User", "id": 1}`  | ok                      |
| `Ok(1)`                    | `{"__type__": "Ok", "value": 1}` | Should                  |
| `Range`                    | `{"__range__": [start, end]}`    | Should                  |
| `Pid` / `Ref` / `Function` | —                                | ошибка, не «пропустить» |

## Проверка

```sh
go test ./internal/runtime/ ./internal/prelude/ -race
go test ./internal/runtime/ -run TestImmutability
go test ./internal/runtime/ -run TestStructuralSharing
go test ./internal/runtime/ -run TestEquality
go test ./... -run TermOrder
go vet ./internal/runtime/...
```

Property-тесты (скилл `brig-test`) — обязательны для:

- иммутабельности (`old` после `Put`/`Set` не меняется);
- сложности (append O(1) amortized, read O(log n)) — **инвариантом**, не
  бенчмарком;
- round-trip `Map`/`Vec` через сериализацию (где применимо);
- term order: транзитивность на смешанных списках.

## Частые ошибки

- **`Vec.set` мутирует исходный вектор** — нарушает #13. Симптом:
  property-тест «old не меняется после `Set`» падает; в VM алиасы
  наблюдают неожиданное значение.
- **`Map` считает или хранит `nil` вместо `None`** — `m["a"]` обязан быть
  `Option`. Симптом: `Option.match`/`?` не срабатывают; паттерны на `Some`
  не матчатся.
- **Term order отклонён от §5.3** — `Bool` перед атомами, `Range` на
  позиции §5.3 (не «где-то между ними»). Симптом: сортировка смешанного
  списка даёт другой порядок, чем в дизайне; golden-тест порядка падает.
- **Атом хранится как строка без интернирования** — ломает identity.
  Симптом: `:ok == :ok` возвращает `false` в редких случаях; сравнение
  зависит от пути создания атома.
- **Односвязный List используется как очередь** — O(n) на append; запрещено
  для паттернов роста. Симптом: property-тест на сложность падает; на
  больших входах — квадратичное время. Queue — stdlib (Okasaki), nice to
  have §2.8.
- **`Decimal × Float` не падает** — приведение вместо ошибки. Симптом:
  `dec"1.5" * 2.0` даёт число вместо ошибки; golden-тест семантики падает.
- **`Ok(1)` хранится как кортеж `(:ok, 1)`** — ломает §2.9. Симптом:
  `Ok(1) == (:ok, 1)` неожиданно `true`; pattern-matching по варианту
  ломается.
- **`Pid`/`Ref`/`Function` сериализуются** — «пропустить поле» вместо
  ошибки. Симптом: JSON без предупреждения теряет данные; при
  round-trip — молчаливое расхождение.
- **Новый вид значения не добавлен в `order.go`** — паникует или
  сортируется в конец. Симптом: `sort` на смешанном списке с новым типом
  падает в VM.
- **Прелюдия размазана по `runtime`** — нарушает структуру. Симптом:
  циклические импорты, `runtime` тянет `internal/prelude` и наоборот.
