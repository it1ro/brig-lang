# 20. Эксплуатация, принятие языка, процесс (утверждено 2026-09-27)

## Эксплуатация

| Вопрос | Решение |
|---|---|
| Отчёты о падениях | VM излучает `[:vm, :actor, :crash]` в шину `Telemetry` (16): причина, stack trace (T-79), контекст — супервизор, имя из реестра, `trace` (13). По умолчанию — структурный лог; Sentry-совместимый экспорт — пакет; последние падения видны в `brig observe`. Второго механизма рядом с `Telemetry` нет |
| HTTP-кэширование | плаги в `Http`: `Plug.conditional` (ETag / Last-Modified, `304`), `Plug.cache_control` |
| Отдача файлов | `Conn.send_file(path)` — команда порта запроса (B2): Go отдаёт файл через `sendfile` с поддержкой `Range`, минуя run-loop. Ассеты с хешем в имени (C8) — `Cache-Control: immutable`, в том числе при раздаче из payload бинарника |

## Принятие языка

| Вопрос | Решение |
|---|---|
| Редакторы до LSP | грамматики **tree-sitter** для `.brig` и `.bt` в отдельных репозиториях организации; тесты — примеры спеки и `testdata` парсера, расхождение с `brig.ebnf` ловится в CI. Даёт подсветку в Neovim, Helix, Zed и на GitHub до LSP (C7) |
| Язык документации | **английский основной, русский — перевод** учебника и гайдов. Спеку и внутренние документы (включая это исследование) перевести к 1.0 |
| Путь обучения к выходу Calmar | интерактивный тур языка в песочнице (B6); «Brig by example»; гайд Calmar на примере Lookout; «С Phoenix/Rails на Calmar». Все примеры проверяются в CI, как примеры спеки (§0.10) |

## Процесс

| Вопрос | Решение |
|---|---|
| Изменение языка к 1.0 | **лёгкий RFC в репозитории**: каталог `rfcs/`, шаблон (мотивация, дизайн, альтернативы, совместимость, соответствие §0 и §16), стадии `draft → accepted → implemented`; решает мейнтейнер. Принятый RFC порождает задачи `edit-spec`. Это исследование — первый источник RFC |
| Товарные знаки | **простая политика до 1.0** в духе Python/Rust: имена Brig, Calmar, Whelk можно упоминать и использовать в названиях пакетов сообщества без претензии на официальность; официальные пакеты — в организации проекта. Формальная регистрация — по мере роста |
