# 15. View-слой: шаблоны `.bt` (утверждено 2026-09-27)

Шаблоны — отдельный язык разметки со вставками выражений Brig. Их
компилирует тулчейн `brig` (общий формат для Calmar и будущих фреймворков),
хелперы — в Calmar. Это не макросы и не сигилы (§16, §3.2): код
вызывающего не меняется, шаблон компилируется в обычный модуль.

## Решения

| Вопрос | Решение |
|---|---|
| Данные | **объявленные параметры**: `{params monitors: List<Monitor>, title: Str}` → функция с record-паттерном; внутри — просто `{monitor.name}`. Опечатка или нехватка данных — ошибка при вызове; аннотации проверяются как контракты (09) |
| Компоненты | **теги-компоненты**: `<StatusBadge status={m.status} />` → вызов функции `status_badge({ status: … })`; вложенная разметка — параметр `inner`. Заглавная буква отличает компонент от HTML-тега. Компонент — шаблон или обычная `pub fn` |
| Экранирование | **по контексту**, как Go `html/template`: текст, атрибут, URL, `<script>`, `<style>`. Опасные схемы URL (`javascript:`) блокируются; в `<script>` — только JSON-кодированное значение |
| Формат компиляции | **статика + динамика**: неизменные куски — константы `Bytes`, значения — слоты; ответ — iodata без склеек. Задел под серверный UI (C8): передавать только изменившиеся слоты |
| Ветвления | `:if` / `:else` на соседних элементах; `:case={expr}` на обёртке и `:of={pattern}` на детях (паттерны Brig, первый совпавший; непокрытый `:case` — авто-raise, как `match`) |
| Проверки | **строго при сборке**: незакрытые/перепутанные теги, неизвестный компонент или параметр — ошибка с `line:col` в `.bt`. Ошибки рантайма указывают на строку шаблона (исходные карты) |
| Не-HTML | `.txt.bt` — тот же синтаксис без HTML-экранирования, директивы — блоками (для `Mailer` и скриптов) |
| Лэйаут | в пайплайне: `Plug.put_layout(Layouts.app)`; действие переопределяет `Conn.put_layout(…)` или `:none`. Ссылка на функцию, не строка |

## Синтаксис

| Конструкция | Смысл |
|---|---|
| `{params name: Type, …}` | параметры шаблона (первая значимая строка); `Option<T>` можно не передавать |
| `{import Module}` | модули, в которых ищутся теги-компоненты; неоднозначность — ошибка сборки |
| `{expr}` | вставка выражения Brig с экранированием по контексту |
| `{raw(x)}` | явный отказ от экранирования (`x` должен быть `Html.Safe`) |
| `attr={expr}` | значение атрибута; `false`/`None` — атрибут не выводится |
| `:for={x <- list}` | повторить элемент |
| `:if={cond}` / `:else` | условие (строгий `Bool`) и «иначе» на следующем соседнем элементе |
| `:case={expr}` / `:of={pattern}` | выбор по паттернам |
| `<Component a={…}>…</Component>` | вызов компонента; содержимое → `inner` |
| `{# … #}` | комментарий, в вывод не попадает |

## Как данные попадают в шаблон

`Conn.render(T.index, { monitors: monitors })` передаёт в шаблон
`conn.assigns` (то, что положили плаги: `csrf_token`, `flash`, текущий
пользователь) **плюс** явные данные действия. Шаблон берёт только то, что
объявил в `{params …}`; объявленного, но не переданного значения нет —
ошибка при вызове с указанием шаблона и параметра. Исключение — параметр
типа `Option<T>`: его можно не передавать, он будет `None` (отсутствие
выражено в типе, §0.4; аргументов по умолчанию нет, §16).

## Пример

```text
{params monitors: List<Monitor>}
{import LookoutWeb.Components}

<p :if={monitors == []}>Пока пусто.</p>
<table :else>
  <tr :for={m <- monitors}>
    <td><a href={Router.path(MonitorController.show, m)}>{m.name}</a></td>
    <td><StatusBadge status={m.status} /></td>
  </tr>
</table>
```

Компонент `lib/lookout_web/components/status_badge.html.bt`:

```text
{params status: Atom}

<span class={"badge badge-\(to_str(status))"} :case={status}>
  <b :of={:up}>работает</b>
  <b :of={:down}>упал</b>
  <i :of={_}>неизвестно</i>
</span>
```

Полные примеры — `demo/lib/lookout_web/templates/` и `components/`.

## Что потребуется

| Что | Где |
|---|---|
| парсер `.bt`, контекстное экранирование, компилятор в модуль, исходные карты | тулчейн `brig` |
| `Html.Safe`, рантайм слотов, iodata | stdlib `Html` |
| `Conn.render`, `put_layout`, `Router.path`, `Form`-хелперы | Calmar |
| серверный UI поверх слотов (diff) | после MVP (C8) |
