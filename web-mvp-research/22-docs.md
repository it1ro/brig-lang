# 22. Документирование кода и доктесты (утверждено 2026-09-27)

Сейчас в спеке docstrings (`@doc`) — Nice (§16), `brig doc` — упоминание.
Для экосистемы пакетов документация — первое, что видит пользователь, а
доктесты держат примеры рабочими. Инфраструктура почти есть: REPL-формат
примеров (блоки ```` ```brig repl ```` в самой спеке), `check-examples`,
тест-раннер `Test`, многострочные строки (L9).

## Решения

| Вопрос | Решение |
|---|---|
| Синтаксис | **doc-комментарии `##`** непосредственно перед `pub fn`, `type` или `module` — Markdown, как `///` в Rust. Лексер уже считает `##` комментарием, так что это обратно совместимо; парсер сохраняет их в AST, компилятор — в метаданные байткода (console, LSP). `@`-атрибуты не вводятся |
| Доктесты | блок ```` ```brig repl ```` внутри `##`: строки `> выражение` и ожидаемый результат — тот же формат, что в спеке. Ожидаемое **разбирается как выражение и сравнивается через `==`**, а не строкой; ошибка — строка `raise (:not_found, 42)`. Каждый блок исполняется в `Test.isolated` (16) при `brig test`; `brig norun` — пример без исполнения |
| Генерация | `brig doc` — статический сайт из `##`, аннотаций типов и правил `validate/1` (09), офлайн. Пакеты — исходники (10), поэтому **Chandler собирает документацию каждой версии**, как hexdocs/docs.rs. Та же документация — в LSP-подсказках и в console: `h Monitor.changeset` |
| Уровень | **Should для web-MVP** (сейчас Nice в §16): стартовые пакеты — Calmar, Whelk, Postgres, Mailer — документированы. `brig check` предупреждает о `pub fn` без `##`; `brig publish` **требует** документацию модуля и всех `pub fn`. Ссылки `[Monitor.changeset]` проверяются, битая ссылка — предупреждение |

## Пример

```brig
## Мониторы: создание, валидация и представление для JSON и URL.
module Lookout.Monitors.Monitor

## Параметр для URL — идентификатор строкой.
##
## ```brig repl
## > Monitor.to_param(Monitor{ id: 42, name: "a", url: "https://a.test",
##     interval_ms: 30_000, status: :up, last_checked_at: None })
## "42"
## ```
pub fn to_param(m) -> to_str(m.id)
```

В демо — `corpus/lookout/lib/lookout/monitors/monitor.brig`.

## Что где

| Что | Где |
|---|---|
| сохранение `##` в AST, метаданные в байткоде | парсер, компилятор (`brig build` по умолчанию вырезает их из payload, флаг — оставить) |
| доктесты | `brig test` (переиспользует разбор REPL-блоков `check-examples`) |
| `brig doc`, проверка ссылок | тулчейн |
| сборка документации пакетов | Chandler (после MVP, 10) |
| `h` в console, hover в LSP | тулчейн (C7) |
